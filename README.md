# Cloud DevOps

A workflow bundle for planning and operating cloud infrastructure and DevOps delivery across AWS, Azure, and Google Cloud.

## Workflow areas

- Cloud architecture, account setup, networking, and IAM.
- Infrastructure provisioning with Terraform and related tools.
- Containerization and Kubernetes orchestration.
- CI/CD pipeline design, testing, deployment, and rollback.
- Monitoring, logging, metrics, and distributed tracing.
- Cloud security, secrets management, and cost optimization.

## Usage

Use this skill when coordinating an end-to-end cloud or DevOps workflow. It helps identify the appropriate specialist skills for each phase, organize implementation steps, and verify the result.

The workflow references related skills by name. Confirm that each referenced skill and tool is installed and available in the working environment before invoking it. Adapt commands to the selected cloud provider and project rather than assuming every phase applies.
